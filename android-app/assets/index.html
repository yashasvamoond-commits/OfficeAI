An offline-friendly guide to OfficeCLI: the command-line toolkit for reading, creating, editing, validating, and rendering Word, Excel, and PowerPoint files.

Read the offline README ↓Download source ZIP ↗
About this Android app: This is an offline reference companion, not a port of the OfficeCLI command-line engine. The upstream CLI targets desktop operating systems; Android document editing is not included. The APK bundles the upstream README and a curated source archive for offline reference.

What OfficeCLI does

📄 Word

Create, inspect, and edit DOCX documents, tables, styles, images, comments, and more.

📊 Excel

Read and update workbooks, formulas, charts, pivot tables, formatting, and sheets.

🎞 PowerPoint

Build and inspect presentations with slides, shapes, tables, charts, and previews.

👁 Render & review

Render documents to HTML, SVG, or screenshots for an AI-friendly visual feedback loop.

Quick start (desktop)

# macOS / Linux curl -fsSL https://raw.githubusercontent.com/iOfficeAI/OfficeCLI/main/install.sh | bash # Create and preview a presentation officecli create deck.pptx officecli add deck.pptx / --type slide --prop title="Hello, World!" officecli view deck.pptx html
